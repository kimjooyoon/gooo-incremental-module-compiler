# Incremental module compiler v1

## Authority split

`.gooo/incremental-compiler.gooo` is the source of meaning. It declares the
twelve-cell denominator, the `REFUTED > UNKNOWN > CLOSED` reduction, the six
UNKNOWN fields, and the Go generation plan. A module `.gooo` source owns its
semantic digest, dependency edges, invalidation rules, and test ownership. Go
parses those declarations, executes the graph and cache checks, and emits a
derived Go artifact.

The implementation is deliberately a compiler slice, not a package registry:
it does not mutate an input checkout, execute target tests, or infer semantic
equivalence from a cache hit.

## Module source

```text
module "demo/shared" release "v1.0.0" semantic_digest "sha256:<64 lowercase hex>" {
  dependency "demo/core" release "v1.0.0" semantic_digest "sha256:<core digest>" edge "shared-core" invalidates "core-semantic"
  export "SharedValue"
  invalidation "shared-semantic" kind "semantic" scope "dependents"
  test_owner "shared-test" owner "demo/shared" covers "demo/shared,demo/core" kind "unit" command "go test ./shared"
}
```

The semantic digest is SHA-256 over the canonical declaration of identity,
release, exports, dependency declarations, invalidation rules, and test
ownership. Source comments and source-byte digests are intentionally outside
that semantic view. A dependency digest is still required to close graph
resolution; a missing dependency digest is typed UNKNOWN.

## Incremental execution

The cold run compiles every module and executes every owned test. The warm run
starts with semantic changes, follows only edges whose declared invalidation
rule is `semantic`, and reuses an immutable module/test cache entry only when
all declared identities match. A stale entry is REFUTED. A nonsemantic change
does not seed the affected set, so a matching semantic cache may be reused.

Every run records the exact integer lists and counts for compiled/reused
modules and selected/executed/reused/failed/unknown tests. The paired metrics
also contain generated bytes, compile/build/test/conformance/integration
milliseconds, and peak RSS KiB.

An improvement value is emitted only if the source, scenario, contract,
toolchain, and graph digests are all valid and equal for the pair. Otherwise
the improvement field remains UNKNOWN. An independent full oracle is required
for semantic closure; cache reuse by itself cannot close a case.

## Optional released inputs

`-link-graph` and `-runner-release` are optional. If supplied, they are checked
against [`contracts/upstream-lock-v1.json`](../../contracts/upstream-lock-v1.json)
and the lock's immutable release identities. The compiler never consumes a
sibling checkout. The lock retains the tag object, target commit, release
identity, asset name, size, and asset digest for the linker, causal runner, and
bootstrap release.

## Conformance

The `.gooo/conformance.gooo` manifest owns the fixed five-case corpus. Its
reports are written only to the caller-owned output directory. CI checks the
three-module leaf change, transitive shared dependency change, comment-only
change, missing dependency digest UNKNOWN, and stale cache REFUTED. It then
builds every generated Go artifact and uploads the exact inventory and runtime
evidence.
