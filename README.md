# gooo-incremental-module-compiler

An executable, digest-aware incremental module compiler for Gooo. The source of meaning is
[`.gooo/incremental-compiler.gooo`](.gooo/incremental-compiler.gooo): it owns the fixed
denominator, judgment precedence, UNKNOWN tuple, invalidation vocabulary, and Go
generation plan. Go supplies only parsing, execution, canonical hashing, and emission.

The compiler accepts independently declared `.gooo` modules. Each module declares its
semantic digest, dependency edges, invalidation rules, and test ownership. A warm plan
invalidates the changed module and its declared semantic dependents; a nonsemantic
comment-only change keeps the same semantic digest and may reuse the module and tests.

The canonical conformance corpus contains exactly five scenarios:

| Scenario | Expected | Purpose |
| --- | --- | --- |
| leaf-change | `CLOSED` | compile only the leaf closure and execute its owned tests |
| shared-dependency-change | `CLOSED` | propagate invalidation from shared to leaf |
| comment-only-nonsemantic | `CLOSED` | reuse matching semantic artifacts despite source comments |
| missing-digest | `UNKNOWN` | preserve the six-field missing dependency digest tuple |
| stale-cache | `REFUTED` | reject a cache hit whose semantic identity is stale |

Every case records cold and warm exact integer counts for compiled/reused modules,
selected/executed/reused/failed/unknown tests, generated bytes, wall milliseconds, and
peak RSS. An improvement value is emitted only when scenario, source, contract, and
toolchain digests match; cache hits never close semantic verification without an
independent full-oracle comparison.

The linker graph and causal runner are optional inputs. When supplied, they must be
release-bound records for `gooo-module-linker v0.1.1` and
`gooo-causal-verification-runner v0.1.1`; sibling checkouts are never read. The pinned
identities are recorded in [`contracts/upstream-lock-v1.json`](contracts/upstream-lock-v1.json).

GitHub Actions is the verification authority. CI runs Go 1.27, builds the compiler and
every generated Go artifact, runs tests/vet, executes the conformance corpus, and uploads
one exact evidence artifact. Local Go test, build, vet, and conformance execution is not
part of the development contract. The root README is excluded from inventory counts.

The repository was initialized from the immutable
`gooo-repository-bootstrap v0.1.1` bootstrap release. Post-bootstrap implementation is
kept on one open pull request; failed or non-immutable release attempts are retained and
never deleted or overwritten.
